# Franchise Performance: 
Project provides a comprehensive multi-dimensional analysis of Bakehouse franchise locations using Databricks SQL. It systematically evaluates each franchise’s commercial and customer-facing performance by integrating review sentiment, quantitative sales, and geographical data, all sourced from real sample datasets.

The core analyses include:

Extracting and quantifying customer ratings embedded in review text for each franchise and day.
Counting the number of reviews received over time, by franchise, to gauge customer engagement.
Employing built-in AI models for automated sentiment analysis across all reviews, adding qualitative insight.
Mapping and ranking Bakehouse’s geographical footprint by tallying franchise counts per country.
Summarizing sales performance by franchise and product, including both units sold and total revenue.
Mining negative review text to surface the most common product-specific pain points, supporting targeted quality improvements.
